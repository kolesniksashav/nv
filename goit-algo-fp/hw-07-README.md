# Моделювання кидання двох ігрових кубиків

## Опис завдання
Метою цього завдання є використання **методу Монте-Карло** для моделювання великої кількості кидків **двох чесних шестигранних кубиків**, обчислення сум чисел, що випадають, та визначення **ймовірності кожної можливої суми** (від 2 до 12).

Отримані експериментальні ймовірності порівнюються з **аналітичними значеннями**, відомими з теорії ймовірностей.

## Теоретичні відомості
При киданні двох чесних кубиків існує **36 рівноймовірних комбінацій**.  
Ймовірність кожної суми визначається як:

P(сума) = кількість сприятливих комбінацій / 36

Наприклад:
- сума **7** має 6 комбінацій → 6/36  
- суми **2** і **12** мають по 1 комбінації → 1/36  

АНАЛІТИЧНІ ЙМОВІРНОСТІ = {
    2: 1 / 36,
    3: 2 / 36,
    4: 3 / 36,
    5: 4 / 36,
    6: 5 / 36,
    7: 6 / 36,
    8: 5 / 36,
    9: 4 / 36,
    10: 3 / 36,
    11: 2 / 36,
    12: 1 / 36,
}

## Реалізація методу Монте-Карло
У програмі:
1. Виконується **1 000 000 симуляцій** кидків двох кубиків.
2. Для кожного кидка обчислюється сума.
3. Підраховується кількість появ кожної суми.
4. Ймовірність обчислюється як відношення кількості появ суми до загальної кількості кидків.

## Висновки
1. Найбільш імовірною сумою є **7**, що відповідає теорії.
2. Найменш імовірними є суми **2** та **12**.
3. Результати методу Монте-Карло наближаються до аналітичних зі збільшенням кількості симуляцій.
4. Невеликі відхилення пояснюються випадковою природою методу.
5. Метод Монте-Карло ефективний для статистичного моделювання ймовірнісних процесів.
