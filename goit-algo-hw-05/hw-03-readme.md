# Порівняння ефективності алгоритмів пошуку підрядка  
## Боєра–Мура, Кнута–Морріса–Пратта та Рабіна–Карпа

---

## 1. Мета роботи

Метою цієї роботи є порівняння продуктивності трьох класичних алгоритмів пошуку підрядка:

- **Boyer–Moore (BM)**
- **Knuth–Morris–Pratt (KMP)**
- **Rabin–Karp (RK)**

Дослідження виконано на основі двох текстових файлів («стаття 1» та «стаття 2»).  
Для кожного тексту обрано по два підрядки:

1. **Реальний**, який точно знаходиться в тексті.  
2. **Вигаданий**, якого у тексті немає.

Час виконання алгоритмів вимірювався за допомогою `timeit` (2000 повторів на кожен тест).

---

## 2. Використані підрядки

- **Реальний:** `public static int linearSearch`
- **Вигаданий:** `ZZZ_unreal_substring_1`

### Текст 2

## 4. Аналіз результатів

### Текст 1
- Найшвидший алгоритм: **Boyer–Moore**  
- KMP у 4–7 разів повільніший.  
- Rabin–Karp найповільніший (до 4.3 мс).  

**Висновок:** Boyer–Moore найефективніший на тексті 1.

---

### Текст 2
- На реальному підрядку всі алгоритми працюють швидко, але найкращий знову **Boyer–Moore**.  
- На вигаданому підрядку BM майже у **10 разів швидший**, ніж KMP, і у **~15 разів швидший**, ніж Rabin–Karp.  

**Висновок:** Boyer–Moore — найкращий і для тексту 2.
