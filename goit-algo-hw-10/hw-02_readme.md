# ДЗ 2 — Обчислення інтеграла методом Монте-Карло

## Опис завдання
Метою роботи було обчислення визначеного інтеграла функції  
f(x) = x² на відрізку [0, 2] за допомогою методу Монте-Карло та перевірка точності отриманого результату шляхом порівняння з аналітичним розв’язком і результатом функції quad з бібліотеки SciPy.

Реалізовано два підходи методу Монте-Карло:
- метод середнього значення;
- метод «dart throwing» (метод кидання дротиків).

## Метод Монте-Карло
Метод Монте-Карло базується на використанні випадкових чисел. Для обчислення інтеграла випадковим чином генеруються значення x на заданому інтервалі, обчислюється середнє значення функції та множиться на довжину інтервалу.

## Аналітичне рішення
Аналітичне значення інтеграла:

∫₀² x² dx = x³ / 3 |₀² = (2^3 / 3) - (0^3 / 3) = 8 / 3 ≈ 2.6666667

Аналітичне значення інтеграла отримано шляхом знаходження первофункції для x². Це значення використовується як еталон для оцінки точності чисельних методів.

## Реалізація методу Монте-Карло

### Метод середнього значення
Метод середнього значення базується на випадковому виборі точок x з рівномірного розподілу на інтервалі [a, b]. Інтеграл оцінюється як добуток середнього значення функції на довжину інтервалу.

### Метод «dart throwing»
Метод кидання дротиків базується на випадковому генеруванні точок (x, y) у прямокутнику, що покриває графік функції. Частка точок, які потрапили під криву, використовується для оцінки площі під графіком.

## Порівняння результатів

### Отримані числові результати

| Метод                          | Значення інтеграла | Абсолютна похибка     |
|--------------------------------|--------------------|-----------------------|
| Монте-Карло (середнє значення) | 2.6682505010016446 | 0.001583834334978107  |
| Монте-Карло (dart throwing)    | 2.666384           | 0.0002826666666666533 |
| Аналітичний результат          | 2.6666667          | 0                     |
| quad (SciPy)                   | 2.6666667          | ≈ 0                   |

Похибка методу Монте-Карло є малою та зменшується зі збільшенням кількості випадкових точок.

## Аналіз та порівняння методів
Обидві реалізації методу Монте-Карло дають наближені значення, близькі до аналітичного результату.  
При однаковій кількості випадкових точок метод середнього значення показав меншу похибку, ніж метод «dart throwing».

Це пояснюється тим, що метод середнього значення безпосередньо використовує значення функції, тоді як метод кидання дротиків додатково вводить випадковість по осі y, що збільшує дисперсію оцінки.

## Висновки
Метод Монте-Карло є універсальним чисельним методом для обчислення визначених інтегралів.  
Метод середнього значення є більш ефективним і точним для одновимірних інтегралів, ніж метод «dart throwing», оскільки має меншу дисперсію та швидше збігається до точного значення.

Метод «dart throwing» є наочним і добре ілюструє геометричний зміст інтеграла, проте поступається за точністю та ефективністю.  
Результати, отримані обома методами Монте-Карло, підтверджуються аналітичним розрахунком та результатом функції `quad` з бібліотеки SciPy.

Метод Монте-Карло дозволяє з достатньою точністю обчислювати визначені інтеграли, хоча і поступається аналітичним методам та чисельним алгоритмам типу quad за точністю та швидкістю збіжності. Проте цей метод є універсальним і особливо корисним для складних або багатовимірних інтегралів, де аналітичне розв’язання неможливе.
